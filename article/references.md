# Research sources: offline copies

Local copies of the sources cited in the five notes under `research_notes/SMART failure prediction methodology debate/`. Files were downloaded on 2026-10-25 from publishers, USENIX, arXiv, PubMed Central, JMLR, PMLR, IJCAI, university repositories and authors' pages. No shadow-library site was used. The copies live in `article/research/`, which git ignores, so the file links only resolve in a local checkout.

How to read the table:

- **file**: a relative link to the local copy, or "—" when nothing was saved. PDFs were checked to start with `%PDF`. Web pages have two copies: the raw HTML as downloaded, and a Markdown conversion (`md`) made with pandoc 3.1.11 after removing page menus, scripts and forms. Use the HTML copy when the Markdown looks incomplete; for example, the PAKDD dataset page and the MetricGate Obuchowski calculator page load most of their content with JavaScript, so neither copy has much text. For some PubMed Central articles the PDF was blocked, so the full-text HTML page from PMC was saved instead.
- **stance**: copied from the notes and relative to this project's methodology. When a source appears in several notes, its labels are merged. Sources the notes did not label are marked "not labeled".
- **type**: peer-reviewed, preprint, operator blog (Backblaze's own posts and pages), journalism, analyst blog, community (GitHub, forums, wikis, vendor docs), or slides/abstract.
- Each source appears once, under its main aspect. Other aspects it bears on are listed in the aspect column.
- Years in file names for undated web pages (documentation, wikis, repositories) are the year of retrieval.
